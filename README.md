# Academics

A collection of condensed technical documentation and quick reference guides for various programming languages and IT topics.

## Contents

- **C** - Core C programming concepts, memory management, pointers, and system programming
- **General** - Essential IT topics including algorithms, data structures, networking, APIs, protocols, concurrency, architecture patterns, DevOps, and more
- **Linux** - Linux system administration, commands, and shell scripting
- **Python** - Python programming fundamentals and best practices
- **Ruby** - Ruby language features and common patterns
- **SQL** - Database concepts, queries, transactions, and optimization

## Purpose

This repository provides short, practical examples and explanations designed for quick reference and learning. All documentation emphasizes clarity and simplicity with working code examples.
